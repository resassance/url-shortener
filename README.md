# URL Shortener

Веб-сервис для сокращения ссылок на Django. Пользователь регистрируется, добавляет длинную ссылку и получает короткий уникальный код, по которому происходит редирект на оригинальный адрес. Сервис ведёт учёт количества переходов по каждой ссылке.

## Возможности

- Регистрация и авторизация пользователей (стандартная система аутентификации Django)
- Добавление длинных ссылок и автоматическая генерация короткого кода (6 символов, буквы + цифры)
- Редирект по короткой ссылке на оригинальный URL
- Подсчёт количества переходов по каждой ссылке
- Список собственных ссылок для авторизованного пользователя
- Админ-панель Django для управления ссылками

## Стек технологий

- Python, Django
- SQLite (база данных по умолчанию)
- Django Forms (кастомные формы регистрации, входа и добавления ссылок)
- HTML/CSS (шаблоны Django)

## Как это работает

Модель `Link` хранит оригинальный URL и связанный с ним короткий код. Код генерируется автоматически при сохранении объекта, если он ещё не задан, используется модуль `secrets` для криптографически надёжной случайной генерации, а уникальность проверяется прямым запросом к базе. При переходе по короткой ссылке `views.redirect_view` находит соответствующую запись, увеличивает счётчик переходов и перенаправляет пользователя на оригинальный адрес.

Добавлять ссылки может только авторизованный пользователь: неавторизованный запрос на создание ссылки перенаправляется на страницу входа.

## Установка и запуск

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/resassance/url-shortener.git
   cd url-shortener
   ```

2. Создайте и активируйте виртуальное окружение:
   ```bash
   python -m venv venv
   source venv/bin/activate  # Windows: venv\Scripts\activate
   ```

3. Установите Django:
   ```bash
   pip install django
   ```

4. Примените миграции:
   ```bash
   python manage.py migrate
   ```

5. (Опционально) создайте суперпользователя для доступа к админ-панели:
   ```bash
   python manage.py createsuperuser
   ```

6. Запустите сервер разработки:
   ```bash
   python manage.py runserver
   ```

7. Откройте в браузере [http://127.0.0.1:8000/](http://127.0.0.1:8000/)
